What MedICS is

MedICS (Medical Image Computing Suite) is a desktop application for loading, inspecting and analyzing medical images. Image viewing, Python scripting, data import and third-party tools all live in one window instead of being spread across separate programs.

Key features

AreaWhat you get
Image I/OOpen DICOM (including JPEG 2000 and OCT series), TIFF stacks, NIfTI, HDF5, MATLAB .mat, PNG/JPEG, video and more.
PreviewInspect images, volumes, tables, Markdown and code — with slice navigation and window/level, without changing the file.
ImportLoad image sequences, single files and whole DICOM folders, with drag-and-drop and background progress.
PythonAn interactive console and the PyEditor IDE share one live workspace.
WorkspaceKeep every result in a named workspace and save it to a .med file.
ToolboxesFilePreview, ImportData, PyEditor and JupyterLab open as tabs beside your work.
ExtensionsAdd new tools and panels from installable packages — no rebuild of MedICS required.
AI assistantAsk questions or hand off multi-step tasks; each action that changes data needs your approval.

Supported formats

TypeFormats
ImagesPNG, JPEG, BMP, GIF, WebP, ICO, PPM/PGM/PBM, SVG, single-frame TIFF
VolumesNIfTI, MetaImage, DICOM series, stacked TIFF, MedICS image bundles
Scientific containersHDF5, MedICS .med, MATLAB .mat, NumPy .npy/.npz
TablesCSV, TSV, Excel, Parquet
DocumentsMarkdown, plain text and source code
VideoMP4, AVI, MKV, MOV, WebM, WMV, M4V, MPG/MPEG, OGV, 3GP
