Python console & workspace

Work with data in Python, inspect your variables, and save or load a workspace.

Python console & workspace

The workspace

When you import an image, open a file or run code, the results are kept in a workspace. The Variables panel lists everything in it. The Python console and PyEditor share the same workspace, so a variable created in one is immediately available in the other.

The Python console

Open the Jupyter tab at the bottom of the window. It is an interactive console with the scientific stack ready to use — NumPy and Matplotlib, plus a ws handle to your workspace:

import numpy as np
ws.keys()                        # list the variables in the workspace
print(ws['brain_volume'].shape)

Running scripts

Write a script in PyEditor and press F5 to run it. It executes in the live console, so it sees the same variables you do.

Saving and loading

Action Where
Save the workspace to a .med file File → Save Workspace
Choose a location and name File → Save Workspace As…
Load a saved workspace File → Open Workspace
Protect a long session turn on auto-save in Preferences
